# Starter offline recitation: Al-Fatiha

The bundled file `assets/audio/starter-fatiha.ogg` is a complete recording of Surah Al-Fatiha.

- Original: https://commons.wikimedia.org/wiki/File:001Fatiha.ogg
- Original uploader/credited author: kuran*sunnet*islam*
- License: Creative Commons CC0 1.0 Universal (public-domain dedication)
- License text: https://creativecommons.org/publicdomain/zero/1.0/
- Wikimedia Commons original SHA-1: `964ec3ee455b2569188e79374cfdd9b0db2879e9`
- Size: 642,671 bytes, duration approximately 48 seconds.

The audio is provided as a standalone offline listening sample. It does **not**
share the word timing metadata of the Mishary Alafasy aligned recitation, and
must not be used for per-verse synchronized highlighting.

The build workflow fetches the original from Wikimedia Commons and verifies
the SHA-1 before committing the bundled asset. No download at first launch is
needed once the asset has been included in the Android application package.
