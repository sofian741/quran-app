# Quran App — Flexible Mushaf Prototype

## التشغيل محليًا
من داخل مجلد المشروع شغّل أي خادم محلي، مثل:

```bash
npx serve . -l 3000
```

ثم افتح:
- `http://localhost:3000/` للصفحة الرئيسية.
- `http://localhost:3000/quran.html` للمصحف.

للتجربة على الهاتف، افتح نفس المنفذ باستخدام IPv4 الخاص بالكمبيوتر وهما على نفس شبكة Wi‑Fi.

## الموجود الآن
- الصفحة الرئيسية.
- قارئ قرآن بنظام صفحات دون تمرير رأسي.
- تقسيم تلقائي للمحتوى حسب أبعاد الشاشة.
- تغيير حجم الخط وتباعد السطور.
- ألوان جاهزة وألوان مخصصة.
- تقليب بالسحب أو الأزرار.
- حفظ آخر موضع قراءة والإعدادات.

## مهم قبل النشر
راجع `SOURCES.md` وكتلة الحقوق في نهاية `data/quran-uthmani.txt`، وتأكد من شروط إعادة توزيع ملف الخط.
