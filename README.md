# Quran App — مصحف تفاعلي من 604 صفحات

## التشغيل في VS Code

المتطلبات: Node.js 22 أو أحدث، Python 3.12 أو أحدث، وGit. افتح مجلد المستودع في VS Code، ثم Terminal:

```bash
npm ci
npm run qvp:prepare
npm run dev
```

افتح `http://127.0.0.1:4173/` للرئيسية و`http://127.0.0.1:4173/quran.html` للمصحف.
التجهيز الأول ينزل أرشيف QVP المثبت ببصمة SHA-256، ويتحقق من 604 صفحات وربط 6236 آية
وملفات التوقيت الـ19. يحفظ الصفحات في `data/qvp/` والكاش في `.cache/qvp/`؛ كلاهما مولد وغير مضاف إلى Git.
لا يكفي فتح HTML باستخدام `file://`. استخدم localhost أو HTTPS؛ Android يستخدم أصل Capacitor الآمن.
يمكن إعادة استخدام أرشيف محلي موثوق بتحديد `QVP_CACHE_DIR` الذي يحتوي `qvp.tar.gz` ومجلد `qvp/` المفكوك.

QVP هو العرض الافتراضي داخل التطبيق الأساسي، مع نفس الرئيسية والمكتبة والأذكار والتلاوات والإعدادات.
للمحرك السابق اختر «المحرك السابق» من إعدادات القراءة، أو افتح
`http://127.0.0.1:4173/quran.html?engine=legacy`. لم تُحذف ملفاته أو تُنقل بيانات المستخدم.
التبديل لا يمس المفضلة أو التحميلات أو آخر موضع قراءة.

```bash
npm run android:prepare
npm install --no-save --no-package-lock playwright@1.56.1
npm run test:qvp
npm run test:tour:qvp
```

اختبارات المتصفح تحتاج Chromium، ويمكن تحديد مساره بـ`QURAN_BROWSER_PATH` (وللجولة `CHROMIUM_PATH`).
`android:prepare` ينفذ تجهيز QVP تلقائيًا ويضع الصفحات الـ604 داخل `www/`، مع المحرك السابق والتفسير
وتوقيتات الكلمات المحلية. ملفات الصوت تُنزّل عند الطلب كما في التطبيق الحالي.
[تفاصيل الدمج ونتائجه وحدوده](docs/QVP_PRODUCTION_INTEGRATION.md).

## اختبارات مرجع النص والمحرك السابق

```bash
node tests/content.cjs
node tests/audio-core.cjs
```

يفحص الاختبار تغطية 6236 آية و77881 كلمة مرة واحدة وبالترتيب عبر الصفحات الـ604،
ويتحقق من بقاء بصمة ملف Tanzil الأصلية دون تغيير.

الأوامر التالية اختبارات تاريخية للمحرك السابق. اختبارات QVP الحالية هي `npm run test:qvp` و`npm run test:tour:qvp` المذكورة أعلاه:

```bash
QURAN_BROWSER_PATH=/usr/bin/chromium node tests/reader.cjs
QURAN_BROWSER_PATH=/usr/bin/chromium node tests/audio-browser.cjs
QURAN_BROWSER_PATH=/usr/bin/chromium node tests/recitations-browser.cjs
QURAN_BROWSER_PATH=/usr/bin/chromium node tests/all-pages.cjs
```

اختبارات الصوت تستخدم ردود API وصوتًا وهميًا ثابتًا حتى تختبر منطق الواجهة والمزامنة دون
الاعتماد على سرعة الشبكة. التشغيل الحقيقي يحتاج اتصالًا بمصادر التسجيل المبينة في
`SOURCES.md`. يعمل الأوفلاين بعد فتح الموقع عبر HTTPS أو `localhost` وتثبيت Service Worker.


## تلاوة مشاري المتزامنة المضمنة مع Android (نسخة التحضير)

- الهدف في النسخة النهائية: **114 سورة + 6236 آية + تظليل الآية والكلمة + بدء التشغيل من أي آية** بدون إنترنت، مع ظهور السور في «مكتبتي» من أول تثبيت.
- البنية المحلية: `offline/mishary/001.mp3` إلى `114.mp3` مع `001.json` إلى `114.json` لتوقيتات الكلمات الدقيقة وملف manifest.json يُرفض إن كان ناقصًا.
- لأن تسجيل MP3Quran الصوتي مختلف عن تسجيل Quran Foundation المتزامن، لا يُخلط أي توقيت صوتي مع تسجيل آخر. تُستخدم تسجيلات الآيات `Alafasy_128kbps` من EveryAyah مع توقيتات الكلمات **المولدة منها بالضبط** من `cpfair/quran-align` المرخّصة CC BY 4.0.
- `scripts/build-synced-mishary.py` يحصل على التسجيلات الـ6236 الأصلية، يفكها إلى PCM ويحسب الإزاحات بعينات الصوت الفعلية ثم يجمعها إلى 114 ملفًا مضغوطًا بمعدل 48kbps دون تصنيع توقيتات تقريبية.
- `offline-mishary-sync.js` يُحمّل البيانات المحلية، ويعيد استخدام مشغل المصحف وتظليل الآية والكلمة، مع بدء التشغيل من أي آية والتنقل وتكرار الآية والنطاق.
- `offline-mishary.js` يعرض الملفات الـ114 كملفات مضمنة في «مكتبتي»، ويشغّلها من الجهاز بدل التحميل مرة ثانية. هذه الملفات مضمنة في نسخة Android فقط.
- `.github/workflows/prepare-mishary-audio.yml` يحاول إنشاء حزمة مستقلة `assets-mishary-synced-v2` بعد التحقق من اكتمال 114 سورة و6236 آية وملفات الكلمات والتواقيع. **لا يبني APK**.
- بناء Android مستقل، يدوي فقط، ويتطلب حزمة تزامن v2. لا يقبل ملفات MP3Quran v1 التي تفتقد توقيتات الكلمات.
- اختبار البرمجة: `node --test tests/bundled-mishary.test.cjs`؛ يُشترط اختبار تزامن الكلمة وتشغيل التسجيلات فعليًا على الهاتف قبل الإصدار النهائي.

**تنبيه مهم للنشر:** ترخيص CC BY 4.0 يشمل توقيتات cpfair فقط. لم يثبت بعد إذن صريح بإعادة توزيع تسجيلات EveryAyah؛ لا تنشر الحزمة الصوتية المضمنة لمستخدمين قبل تسوية هذا الحق. يُفضّل الاحتفاظ بها كحزمة خاصة للتطوير إلى حين التأكيد.
