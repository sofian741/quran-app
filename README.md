# Quran App — مصحف متجاوب من 604 صفحات

## التشغيل محليًا
من داخل مجلد المشروع شغّل أي خادم محلي، مثل:

```bash
npx serve . -l 3000
```

ثم افتح:
- `http://localhost:3000/` للصفحة الرئيسية.
- `http://localhost:3000/quran.html` للمصحف.

للتجربة على الهاتف، افتح نفس المنفذ باستخدام IPv4 الخاص بالكمبيوتر وهما على نفس شبكة Wi‑Fi.

## الموجود الآن
- الصفحة الرئيسية.
- قارئ قرآن بتخطيط مصحف المدينة الكامل: 604 صفحات وأسطر ثابتة.
- نص Tanzil المحلي مع خط Amiri Quran المرخص، دون اعتماد على الإنترنت.
- عناوين سور وبسملة وعلامات آيات مزخرفة محليًا.
- ضبط تلقائي لحجم السطر بين شاشات الهاتف المختلفة، مع تمرير رأسي احتياطي فقط عندما لا تكفي المساحة.
- ملاءمة داخلية محسوبة لحجم الخط وتباعد السطور، مع إبقاء واجهة الإعدادات للألوان فقط.
- ألوان جاهزة وألوان مخصصة.
- تقليب بالسحب مع معاينة الصفحة التالية، والتنقل من فهرس السور والأجزاء.
- حفظ آخر موضع قراءة والإعدادات.

## التحقق السريع

```bash
node tests/content.cjs
```

يفحص الاختبار تغطية 6236 آية و77881 كلمة مرة واحدة وبالترتيب عبر الصفحات الـ604،
ويتحقق من بقاء بصمة ملف Tanzil الأصلية دون تغيير.

لاختبار عينات العرض في Chromium بعد تثبيت Playwright:

```bash
QURAN_BROWSER_PATH=/usr/bin/chromium node tests/reader.cjs
```

ويفحص `tests/all-pages.cjs` الصفحات الـ604 على خمسة مقاسات شاشة عند تشغيله بالطريقة نفسها.
