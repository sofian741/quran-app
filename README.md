# Quran App — مصحف تفاعلي من 604 صفحات

## التشغيل محليًا
من داخل مجلد المشروع شغّل أي خادم محلي، مثل:

```bash
npx serve . -l 3000
```

ثم افتح:
- `http://localhost:3000/` للصفحة الرئيسية.
- `http://localhost:3000/quran.html` للمصحف.

للتجربة على الهاتف، افتح نفس المنفذ باستخدام IPv4 الخاص بالكمبيوتر وهما على نفس شبكة Wi‑Fi.

## الموجود الآن
- الصفحة الرئيسية.
- قارئ قرآن بتخطيط مصحف المدينة الكامل: 604 صفحات وأسطر ثابتة.
- نص Tanzil المحلي مع خط Amiri Quran المرخص، دون اعتماد على الإنترنت.
- عناوين سور وبسملة وعلامات آيات مزخرفة محليًا.
- ضبط تلقائي لحجم السطر بين شاشات الهاتف المختلفة، مع تمرير رأسي احتياطي فقط عندما لا تكفي المساحة.
- ملاءمة داخلية محسوبة لحجم الخط وتباعد السطور، مع إبقاء واجهة الإعدادات للألوان فقط.
- ألوان جاهزة وألوان مخصصة.
- تقليب بالسحب مع معاينة الصفحة التالية، والتنقل من فهرس السور والأجزاء.
- حفظ آخر موضع قراءة والإعدادات.
- مشغل تلاوة ثابت داخل المصحف، مع التشغيل والإيقاف والتنقل والسحب والسرعة وMedia Session.
- تسجيل مشاري العفاسي المتزامن من Quran Foundation، مع تظليل الآية والكلمة من التوقيتات
  الأصلية للتسجيل نفسه، وإيقاف تظليل الكلمة تلقائيًا عند عدم تطابق عدد الكلمات.
- مكتبة MP3Quran الديناميكية بكل القراء والتسجيلات المتاحة، مرتبة بالأولوية ثم أبجديًا،
  مع البحث وتمييز المصحف الكامل من المختارات.
- تكرار السورة أو الآية أو نطاق داخل السورة، ومتابعة الصفحة الحالية اختياريًا.
- تنزيل السورة عند طلب المستخدم وإدارة الملفات المحفوظة عبر Cache Storage وService Worker.
- المفضلة وفاصلة الآية والصفحة والتفسير الميسر والنسخ والمشاركة والاستماع من قائمة الآية.

## التحقق السريع

```bash
node tests/content.cjs
node tests/audio-core.cjs
```

يفحص الاختبار تغطية 6236 آية و77881 كلمة مرة واحدة وبالترتيب عبر الصفحات الـ604،
ويتحقق من بقاء بصمة ملف Tanzil الأصلية دون تغيير.

لاختبار عينات العرض في Chromium بعد تثبيت Playwright:

```bash
QURAN_BROWSER_PATH=/usr/bin/chromium node tests/reader.cjs
QURAN_BROWSER_PATH=/usr/bin/chromium node tests/audio-browser.cjs
QURAN_BROWSER_PATH=/usr/bin/chromium node tests/recitations-browser.cjs
QURAN_BROWSER_PATH=/usr/bin/chromium node tests/all-pages.cjs
```

اختبارات الصوت تستخدم ردود API وصوتًا وهميًا ثابتًا حتى تختبر منطق الواجهة والمزامنة دون
الاعتماد على سرعة الشبكة. التشغيل الحقيقي يحتاج اتصالًا بمصادر التسجيل المبينة في
`SOURCES.md`. يعمل الأوفلاين بعد فتح الموقع عبر HTTPS أو `localhost` وتثبيت Service Worker.

## مهم قبل النشر
راجع `SOURCES.md` وكتلة الحقوق في نهاية `data/quran-uthmani.txt` قبل النشر.
