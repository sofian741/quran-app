# Quranic Universal Audio timing data

The word-level timing files in this directory were generated from the
`QUD-Technologies/quranic-universal-audio` release **v3.2.0**:

https://github.com/QUD-Technologies/quranic-universal-audio/releases/tag/v3.2.0

The timing metadata is licensed under **Creative Commons Attribution 4.0
International (CC BY 4.0)**:

https://creativecommons.org/licenses/by/4.0/

The files were validated and compressed for local use by this project. The
catalog files retain the audio URLs associated with the matching recordings.
The CC BY 4.0 notice applies to QUD timing metadata; it does not grant or
describe rights in the linked audio recordings. Audio rights must be confirmed
with each recording provider before public distribution or offline storage.
